Privacy Policy

Last updated: 15 October 2026

BTS Studio ("the app") is free, open-source live production software published by Bhoomiputra Tech Solutions Pvt. Ltd. ("BTSPL", "we"), CIN U62099MH2024PTC427684, 201 Janki Niwas, Devrung, Bhiwandi, Maharashtra 421302, India. This policy explains what the app does and does not do with your information.

Summary

  • We do not collect, sell or share personal data.
  • The app has no accounts, no advertising and no analytics or tracking.
  • Your cameras, microphones, screens, media files, recordings and stream keys stay on your computer.

Data processed on your device

To work, the app accesses the devices and files you choose: cameras, microphones and capture cards, screen or window capture, and media files you add. This processing happens only on your computer. Recordings and snapshots are saved to the folder you choose. Settings, presets and stream keys are stored locally in your Windows user profile and are never sent to us.

Network connections the app makes

  • Streaming — when you start streaming, video and audio are sent only to the destinations you configure (for example YouTube, Facebook, Twitch or your own server). Those services' own privacy policies apply.
  • Web browser inputs and data sources — the app loads web pages, CSV/JSON files or Google Sheets only at addresses you enter.
  • Update checks (installer version only) — the app periodically requests a small version file from studio.btspl.tech, which redirects to GitHub Releases. These requests contain no personal data beyond what any web request includes (such as your IP address), which our hosting providers may log for security for a limited time. The Microsoft Store version is updated by the Microsoft Store instead.
  • Web Controller / API — an optional local web server (default port 8088) lets devices on your own network control the app. It does not connect to the internet and can be turned off in Settings.

Children

The app is suitable for students. It does not knowingly collect any information from anyone, including children.

Website

This website does not use cookies or analytics. The download button asks the public GitHub API for the latest release.

Changes

If this policy changes we will update the date above and publish the new version on this page.
