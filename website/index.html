Everything you need for a live show

A full production switcher, graphics system, audio mixer and encoder in one app. Built on Electron and FFmpeg.

Switcher

Preview / Output workflow with a T-Bar, Quick Play, Cut and four programmable transition buttons. Fade to Black in one key.

20+ transitions

Fade, Merge, Zoom, Cross Zoom, Wipes, Iris, Slide, Push, Fly, Cube, Flip, Dip to Black/White, Blur — plus Stingers with alpha.

Overlays & scenes

Four overlay channels for titles and logos. Scenes with up to 10 layers for picture-in-picture, side-by-side and quad layouts.

Inputs

  • Cameras and capture cards
  • Screen & window capture (with system audio)
  • Video, audio, images & GIFs, playlists
  • Web browser / HTML overlays with transparency
  • Titles, colour, bars, audio devices

Keying & picture

GPU chroma key, luma key and colour correction. Position, zoom, crop, rotate, border and rounded corners for every input.

Titles

Built-in templates: lower thirds, breaking news with ticker, cricket score bar, sports score, clock, countdown, full-screen title, social handle and up next. Make your own in the visual Title Designer.

Data sources

Bind title fields to CSV, JSON or Google Sheets data with automatic refresh — ideal for live scores, results and name lists.

Audio mixer

Master, Bus A and Bus B. Per-input trim, delay for lip-sync, 3-band EQ, compressor, noise gate, solo and audio-follow-video. Master limiter, peak meters and headphone monitoring.

Streaming

Stream to up to 3 destinations at once — YouTube, Facebook, Twitch, custom RTMP/RTMPS, SRT or UDP — with auto-reconnect.

Hardware encoding

NVIDIA NVENC, Intel Quick Sync and AMD AMF, or x264 on the CPU.

Recording

Record MP4, MKV, MOV or WebM. MultiCorder records clean ISO files of each camera. Take snapshots at any time.

Outputs

Multiview, and a fullscreen External output on any connected display or projector.

Remote control

HTTP API, a web controller for phones and tablets, and browser-based tally lights for camera operators.

Workflow

Keyboard shortcuts for every key action. Save presets as .btsproj files, with autosave and crash recovery.

How updates work

You install BTS Studio once. After that, new versions arrive automatically from this website.

  1. Check

    At startup and every 6 hours, BTS Studio reads updates/latest.yml on this site.

  2. Download

    If a newer version exists, BTS Studio tells you. Click Download and it fetches the update in the background.

  3. Install

    Restart when it suits you — never in the middle of a show. If you don't, it installs when you next quit.

  4. Manual check

    Any time, use Help → Check for Updates in the app.

Frequently asked questions

Short answers. The User Guide has the details.

Is BTS Studio really free?

Yes. It is free to download and use, with no watermark and no subscription. The source code is released under the MIT licence.

Does it run on macOS or Linux?

Not at the moment. BTS Studio currently supports Windows 10 and Windows 11 (64-bit) only.

Windows shows a SmartScreen warning when I run the installer. Is that safe?

SmartScreen can warn about new or unsigned installers. Make sure you downloaded it from studio.btspl.tech, then choose More info → Run anyway.

Can I stream to YouTube and Facebook at the same time?

Yes. You can send one output to up to three destinations at once — any mix of YouTube, Facebook, Twitch, custom RTMP/RTMPS, SRT or UDP. Each destination uses upload bandwidth, so check your connection speed.

Can I use it for cricket and other sports?

Yes. There is a built-in cricket score bar and a sports score template. Bind them to a Google Sheet, CSV or JSON file, or update them from a phone using the web controller or HTTP API.

Which encoder should I choose?

Use your GPU's hardware encoder if you have one — NVENC (NVIDIA), Quick Sync (Intel) or AMF (AMD). It keeps the CPU free for mixing. x264 works on any PC but uses more CPU.

Do I need to uninstall before updating?

No. Updates install over the existing version and keep your settings and presets.

Where do I report a problem?

Open Tools → Show Log File in the app and include the log with a description of what happened when you contact us.
