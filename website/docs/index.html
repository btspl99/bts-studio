1. Getting started

Install

  1. Download the installer (BTS-Studio-Setup-<version>.exe) from studio.btspl.tech.
  2. Run it. If Windows SmartScreen shows a warning, choose More info → Run anyway (only for installers downloaded from this site).
  3. Follow the steps in the installer. A Start menu and desktop shortcut are created.

First launch

BTS Studio opens with an empty project. The top half shows two monitors: PREVIEW on the left and OUTPUT on the right. Below them are the transition controls, then your inputs, then the audio mixer.

Update your graphics drivers before your first show. Most video problems come from old drivers.

Add an input

Click Add Input (or press Ctrl+I), choose a type — for example Camera or Video — pick the device or file, and click OK. Each input appears as a numbered tile.

Preview vs Output

  • Preview is what you are preparing. Viewers cannot see it.
  • Output (also called Program) is what is live — streamed, recorded and sent to the External output.

Click an input tile to load it into Preview. Number keys 1–9 do the same.

Quick Play, Cut and the T-Bar

  • Quick Play (Space) — transitions Preview to Output using the selected transition and duration.
  • Cut (Enter) — swaps Preview and Output instantly.
  • T-Bar — drag to perform the transition by hand at your own speed. Let go part way to hold a mix.
  • Transition buttons 1–4 — four programmable buttons, each with its own effect and duration (T Y U I).
  • Fade to Black (B) — fades the whole Output to black, and back.

Save your setup with Ctrl+S as a .btsproj preset. BTS Studio also autosaves and offers to recover your project after a crash.

Input settings

Double-click an input's thumbnail (or right-click the tile and choose its settings) to open the input settings. The tabs are:

  • General — name, device or file, loop and other type-specific options.
  • Position / Crop — position, zoom, crop, rotate, border and rounded corners.
  • Colour Correction — brightness, contrast, saturation and other adjustments.
  • Keying — GPU chroma key (green or blue screen) and luma key (remove black or white).
  • Audio — the input's audio options; full controls are in the audio mixer.
  • Layers — place up to 10 other inputs on top of this one, each with its own position.

A camera can only be opened by one application at a time. Close other video apps before adding it.

3. Transitions & Stingers

BTS Studio includes more than 20 transitions: Fade, Merge, Zoom, Cross Zoom, Wipes, Iris, Slide, Push, Fly, Cube, Flip, Dip to Black, Dip to White and Blur. Set the effect and duration for Quick Play and for each of the four transition buttons.

Stingers

A stinger is a short video with an alpha channel (transparency) that plays over the switch — for example a logo that sweeps across the screen.

  • Format: WebM with VP9 and alpha is recommended. Any video format with alpha that FFmpeg can decode will work.
  • Cut point: the moment, in milliseconds from the start, when the switch happens underneath. Set it to the frame where the stinger fully covers the screen.
  • Keep stingers short (about 1 second) and the same resolution as your output.

4. Overlays

Overlays sit on top of Output (and Preview) without changing what is underneath. There are 8 overlay channels, so you can show a logo, a scoreboard and a lower third at the same time.

  • Toggle overlay 1–4 on the selected input with Shift+1–4, or with the overlay buttons on each tile.
  • Turn all overlays off with Shift+0.
  • Title inputs animate in when shown and animate out when hidden, using the title's own animation.

5. Titles & Title Editor

Add a Title input and choose a template:

  • Lower third
  • Breaking news with ticker
  • Cricket score bar
  • Sports score
  • Clock and Countdown
  • Full-screen title
  • Social handle
  • Up next

Edit the text fields in the title's settings — changes appear live. Each field has a name (for example Score) which you use with Data Sources and the API.

Title Designer

Open the visual Title Designer to build your own titles: add text, rectangles, images, clocks, countdowns and tickers, set fonts and colours, position elements, and name the text fields you want to change during the show. Save it and use it like any built-in template.

6. Data Sources

Data Sources fill title fields from a table of data, so you don't have to retype names and scores.

Supported sources

  • CSV — a local .csv file. The first row is the column headers.
  • JSON — a local file or URL containing an array of objects.
  • Google Sheets — paste the sheet's share link. Set sharing to Anyone with the link → Viewer.

Bindings

In the Data Sources window, bind a column to a title field (for example column Runs to the Score field of the Score title). Set an auto refresh interval so the title updates when the source changes.

Row selection

Choose which row is shown. Use Next/Previous to step through rows — useful for player names or results. From the API: /api/?Function=DataSourceNextRow&Value=Players.

7. Audio mixer

Every input with sound has a channel strip with a fader, mute, and peak meter.

Buses

  • M (Master) — goes to stream, recording and External output.
  • A and B — two extra buses, for example a separate mix for headphones or a commentary feed.

Click M, A or B on a strip to route that input to the bus.

Per-input processing

  • Trim — input gain before the fader.
  • Delay — delays audio in milliseconds for lip-sync when video is behind.
  • EQ — 3-band (low, mid, high).
  • Compressor — evens out loud and quiet speech.
  • Noise gate — mutes background hiss between words.
  • Solo — listen to just this input in headphones.
  • AFV (Audio Follows Video) — the input's audio is only heard when it is on Output.

Master

The master limiter stops the output clipping. Pick a headphone monitoring device to listen to the mix. Open the mixer in its own window with F9.

Volume 75 on the fader = 0 dB (unity gain).

8. Streaming

Destinations

Open stream settings and add up to 3 destinations. They stream at the same time. Supported: YouTube, Facebook, Twitch, custom RTMP/RTMPS, SRT and UDP. If the connection drops, BTS Studio reconnects automatically.

Stream keys

Copy the stream key from your platform's live dashboard (YouTube Studio → Go live, Facebook Live Producer, Twitch Creator Dashboard) and paste it into the destination. Treat it like a password — anyone with it can stream to your channel.

Encoder

  • NVENC (NVIDIA), Quick Sync (Intel), AMF (AMD) — hardware encoders, recommended.
  • x264 — software (CPU). Works anywhere but uses a lot of CPU.

Recommended settings

Recommended streaming settings
ResolutionVideo bitrateKeyframe interval
1080p 30 fps4500–6000 kbps2 seconds

Your upload speed should be at least 1.5× the total bitrate of all destinations. Start streaming with Ctrl+Shift+L.

9. Recording & MultiCorder

Record Output to MP4, MKV, MOV or WebM. Start or stop with Ctrl+Shift+R.

MKV is crash-safe. If the PC or app crashes, an MKV file can still be played. An unfinished MP4 usually cannot. Record to MKV and convert later if you need MP4.

MultiCorder (ISO recording)

MultiCorder records selected inputs — usually your cameras — to separate clean files, without titles or transitions, so you can re-edit the show later.

  • Pass-through — saves the source as it arrives without re-encoding. Uses very little CPU, but only works when the source format can be stored directly.
  • Re-encode — encodes each input with the chosen encoder. Works with any source, uses more CPU/GPU.

Snapshots

Press Ctrl+P to save a still image of Output.

10. External output & Multiview

External output

Send Output fullscreen to any connected display — a projector, TV or LED screen. Choose the display in the External output settings. Extend your desktop in Windows display settings first (do not mirror).

Multiview

Press F8 to open Multiview: Preview, Output and all inputs in one window, ideal on a second monitor. Press F9 to open the audio mixer window.

12. Web Controller & API

BTS Studio runs a small web server (default port 8088) so other devices on your network can control it.

Web Controller

On a phone or tablet on the same Wi-Fi, open http://PC-IP:8088/ — replace PC-IP with your PC's local IP address (run ipconfig to find it, e.g. 192.168.1.20).

Tally lights

Open http://PC-IP:8088/tally/?input=1 on a phone mounted near camera 1. The screen turns RED when that input is on Output and GREEN when it is in Preview.

HTTP API

  • GET /api — current state as JSON.
  • GET /api?format=xml — current state as XML.
  • GET /api/functions — list of all available functions.

Call a function with /api/?Function=Name plus parameters. Input can be the input number, its title, or its id.

/api/?Function=Cut&Input=2
/api/?Function=QuickPlay&Input=Camera
/api/?Function=SetText&Input=Score&SelectedName=Score&Value=120/3
/api/?Function=OverlayInput1&Input=3
/api/?Function=StartStreaming
/api/?Function=SetVolume&Input=2&Value=75
/api/?Function=DataSourceNextRow&Value=Players

SetVolume value 75 = 0 dB.

POST with JSON

You can also POST a JSON body with the same parameters:

curl -X POST http://192.168.1.20:8088/api/ \
  -H "Content-Type: application/json" \
  -d '{"Function":"SetText","Input":"Score","SelectedName":"Score","Value":"120/3"}'

The API has no password. Use it only on a trusted local network, and do not forward port 8088 on your router.

New in 1.6

A different picture on each output

In Settings → Streaming, every destination has a Source: Output, Clean feed (without overlays and titles), Preview, a multiview or any single input. Settings → Recording has the same for Recorder 1 and Recorder 2 — for example record the clean feed for editing while you stream the full program.

Vertical streams (Shorts, Reels, TikTok)

Pick a destination resolution of 1080×1920 or 720×1280 (or 1080×1080 for square) and set Framing to Fill. BTS Studio crops the middle of your 16:9 show; move the crop with Crop position (0 = left, 1 = right). Fit keeps the whole picture with black bars instead.

Stream delay

Set Delay (seconds) on a destination to hold it back — useful for contests, sports betting rules or to catch mistakes. The recording and the other destinations are not delayed.

Multi-track, WAV and split recordings

Under Recording, tick buses in Extra audio tracks: Master becomes track 1 and each bus its own named track, so commentary, guests or music can be remixed later. Choose WAV as the format for an audio-only 24-bit recording, and New file every to start a fresh file every few minutes.

New in 1.5

NDI® in and out

Install the free NDI Tools from ndi.video first — BTS Studio uses the NDI runtime it installs. To receive, click Add Input → NDI® and pick a source; it shows red tally on the source when it is on air and green when it is in Preview. To send, open the ⚙ next to External and use the NDI outputs table: give each output a name, choose its source (Output, Clean feed, Preview, a multiview or any input), size and audio bus, then press Start. Sources on another subnet can be added under Settings → Media & Guests → NDI extra IPs.

Capture Card (Pro)

Add Input → Capture Card (Pro) opens a card directly instead of through the webcam layer. Choose the driver (DirectShow, or Blackmagic DeckLink), the device and one of the video modes the card reports, then the input port (SDI, HDMI, component…), whether to deinterlace, and the number of embedded audio channels (2, 8 or 16) and which pair goes to the mixer. Close the card's own software first. Blackmagic cards need Desktop Video and an FFmpeg with DeckLink support (set in External Outputs → Blackmagic). The simple Camera / Capture input is still the lighter choice for webcams.

Better network streams

Stream / IP Cam inputs in H.264 (and HEVC on GPUs that support it) are now decoded on the graphics card with no re-compression — sharper picture and less delay. Other codecs switch to the old compatibility mode automatically; you can also choose it under Decoding.

Guests without port forwarding (BTS Link)

Turn on Settings → Media & Guests → BTS Link. Guest links then start with studio.btspl.tech/link/ and work from any network, without changing your router. Only the call set-up goes through the BTS Link server; the picture and sound go straight between the guest and your PC. For guests on very strict networks, add a TURN server on the same page.

Video delay and input statistics

Each input has a Video delay (Position → Timing, up to 1 second) to line the picture up with the sound. Modules → Statistics now lists every live input with its frame rate, resolution, decode path and dropped frames.

New in 1.4

Faster, higher-quality outputs

Settings → Recording and Streaming now default to GPU — shared hardware H.264. The picture is encoded once on your graphics card and shared by every stream and recording that uses the same settings, so streaming to several platforms while recording costs almost nothing extra. You can also choose x264, x265, NVENC (H.264 / HEVC / AV1), Intel Quick Sync, AMD AMF, ProRes 422 HQ or DNxHR HQ. For recordings choose Constant quality (High, or Lossless for editing). MP4 recordings are crash-safe. Settings → Encoders shows which encoders your PC supports and has an Audio offset to fine-tune lip-sync.

Multiview on any monitor

There are four multiviews. In the Multiview module pick one, choose a layout (2+8, 2+12, 2+16, 2+24, grids…) and press ⚙ for labels, tally borders, audio meters, safe areas, status bar and resolution (up to 4K). Right-click a cell to put a specific input, Output, Preview or a clock in it. To show a multiview on another screen, open Settings → External outputs and choose Multiview 1–4 as the source.

Title Editor

Right-click a title input and choose Edit title…, or open Tools → Title Editor… for a new title. Add text, shapes, lines, images, clocks, timers, tickers and credits from the toolbar; drag to move, use the handles to resize (Shift keeps the ratio, Alt resizes from the centre) and the round handle to rotate. Pink guides show when an object lines up with the centre, the safe areas or another object. In the right-hand panel set fonts, gradients, outlines, shadows and a background box. Under Animation give each object its own In and Out effect, then drag the blue bars in the timeline to set when each one starts and how long it takes. Press Apply to update the input.

External outputs (1.4.1)

Click the ⚙ next to External in the bottom bar. For each output choose the screen (a projector, TV, LED processor or HDMI capture device), the source (Output, Clean feed, Preview, a multiview or any input), Fit / Fill / Stretch, rotation and mirroring, and tick it. Then press External or F7 to turn all ticked outputs on or off. Video wall… spreads one picture across several screens. If the screen list only shows one screen, press Win+P and choose Extend. Blackmagic DeckLink / UltraStudio cards are set up in the same window.

Health and statistics

BTS Studio now warns you when the frame rate drops, an output can't keep up or memory runs low. Modules → Statistics shows CPU, memory, GPU, frame-time graph and each output's encoder and buffer.

Command search

Press Ctrl+K (or click the search box at the top) and type to run any command or put any input into Preview. Settings has a search box too.

New in 1.3

Remote guests

Add Input → Remote Guest. Open the input's settings and copy the link for your network (for example https://192.168.1.20:8089/guest/?k=ABC123) to the guest. They open it in a browser, allow camera and microphone and press Join. The page uses a self-signed certificate, so the guest taps Advanced → Continue once. Guests hear the show without their own voice and see the Output. For guests outside your network, forward TCP port 8089 on your router and, if needed, add a TURN server in Settings → Media & Guests.

Slides, PowerPoint and PDF

Add Input → Slides / PowerPoint, or drag a .pdf / .pptx onto the inputs. PowerPoint files are converted with Microsoft PowerPoint (or LibreOffice) the first time. Change slides with Next / Previous, the SlideNext shortcut, a presentation clicker mapped to it, or the Web Controller.

Any video format

AVI, WMV, MXF, MPEG-2, VOB, FLV and ProRes files are converted once in the background to a playable copy (Settings → Media & Guests to change quality or clear the cache).

Colour wheels and scopes

Input Settings → Colour Correction has Lift, Gamma and Gain wheels, looks and save/load. Open Modules → Scopes for waveform, parade, vectorscope and histogram of the Output, Preview or any input.

Titles and data

The Add Input → Title gallery has 40 templates with categories and search, and Import Photoshop PSD — text layers become fields you can edit and bind to data. In Data Sources you can now use Excel workbooks (they update when you save the file), XML and RSS feeds. Choose All rows on a binding to fill a ticker with every headline.

Telestrator and virtual sets

Click Telestrator in the bottom bar to draw arrows, circles and highlights on the live picture; press Put on air to show the drawings on an overlay channel. Add Input → Virtual Set places green-screen presenters into a News Desk, Talk Show or Tech set; switch between Wide and Close-up shots in the input's settings or with VirtualSetShot.

Audio buses A–G and replay

Right-click a bus in the mixer to send it to Master, to headphones, or to any audio output (in-ear monitors, a PA or an IFB feed). Each stream destination can use a bus as its audio. In Instant Replay, tick B follows A to play the same moment from another angle on Replay B, and set a music file in replay settings to play under Highlights.

PTZ cameras

Open Modules → PTZ Control, pick a camera input and click Setup to enter its IP address (VISCA over IP). Drag the joystick to move, use the rocker to zoom, click a preset to recall it and Shift+click to store. Right-click a preset → Make input to get an input that moves the camera when you select it.

TCP API, live preview and scripts

Bitfocus Companion, Stream Deck plug-ins and tally boxes can connect to the vMix-compatible TCP API on port 8099 (FUNCTION Cut Input=2, SUBSCRIBE TALLY). http://PC-IP:8088/api/mjpeg?Input=program gives live video for any browser or OBS. The Scripts panel now offers JavaScript scripts with await API.Cut({ Input: 2 }), sleep() and loops.

13. Updates

BTS Studio checks for updates automatically at startup and every 6 hours. When a new version is available you are notified and can download it. Install by restarting the app when convenient; otherwise it installs the next time you quit.

To check yourself, use Help → Check for Updates. Your presets and settings are kept.

14. Troubleshooting

Camera is busy or shows black

Another app (Zoom, Teams, browser, camera app) is using the camera. Close it, then remove and re-add the input. Check Windows Settings → Privacy → Camera allows desktop apps.

FFmpeg errors

Usually caused by an unsupported file, a missing file, or an encoder your GPU doesn't support. Try another file, re-encode it, or switch the encoder to x264 to test. The exact message is in the log file.

Stream won't connect

Check the stream key (paste it again — no extra spaces), the server URL, and that the event is set to live on the platform. Keys can change when you create a new live event.

Windows Firewall prompt

The first time the API/web controller starts, Windows asks whether to allow BTS Studio on networks. Allow it on Private networks so phones and tablets can connect.

Choppy video or high CPU

Update your GPU drivers from NVIDIA, AMD or Intel. Use a hardware encoder, lower the output resolution or frame rate, and close other heavy apps.

Log file

Open Tools → Show Log File. Include it when reporting a problem.
